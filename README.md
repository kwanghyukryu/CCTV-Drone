## Overview
This project implements a computer-vision-based control and surveillance system for a DJI Tello drone using Python. The system enables real-time drone movement, face tracking, image capture, and basic surveillance behaviors by combining OpenCV-based vision processing with keyboard and autonomous controls.

The project is modular, separating drone control, vision processing, and application logic for clarity and extensibility.

---

## Features
- Real-time face detection using OpenCV Haar Cascades
- Autonomous face tracking and movement adjustment
- Manual keyboard-based drone control
- Image capture from drone camera feed
- Basic surveillance and movement behaviors
- Modular and extensible Python codebase

---


## Hardware Requirements
- DJI Tello drone
- Computer with Wi-Fi capability
- Camera access through Tello drone

---

## Software Requirements
- Python 3.x
- OpenCV
- NumPy
- djitellopy library
- Keyboard input support (OS-dependent)
